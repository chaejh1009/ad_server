# 광고 서버 문서

[`ad-server-routing/README.md`](ad-server-routing/README.md)에서 시작한다. 현재 구현의 HTTP 경로, 관리 명령, 계층별 호출 흐름, Mongo·파일 계약과 파일별 함수 설명을 연결한다. 플레이어 스냅샷 검사·비교·누락 기록·계약 생성·폴더 인계·정규화 미리보기와 CDC 준비 기록 명령도 포함한다.

파일별 문서는 `ad-server-routing/files/<프로젝트 상대경로>.md`에 있다. 코드 탐색 문서이며 수업에서 앞으로 만들 기능은 현재 구현으로 기록하지 않는다.
